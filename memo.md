## Recommendation

Our recommendation would be to run a pilot. The model's list churn 
rate was 69.4% compared to the overall rate of 26.5%. Using the trees list, 
we would run a small test before the full roll out. We would want anywhere 
from 500 to 1000 participants. We would split the group randomly so some get 
the offer and some don't. We calculated a break even point of 13.5%, which fell 
within the 10 to 20% save rate range. Because of this the data couldn't tell 
us the save rate. This test would help us find the save rate. We can then use 
our save rate from the pilot test to compare to 13.5%. The model does find 
customers are likely to leave and it does not show that the offer will change 
their minds. The contract rule list loses money at every save rate tested. 
That is a reason we want to use the trees model.
